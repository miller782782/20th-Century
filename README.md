# Network Visualizations and Natural Language Processing with Python

This was Achievement 1 of CareerFoundry's Data Visualizations with Python specialization course as part of their Data Analytics program.

There were 7 tasks to complete in the achievement:
1. Intro to Freelance and and Python Tooks
2. Setting Up the Python Workspace
3. Virtual Environments in Python
4. Accessing Web Data with Data Scraping
5. Text Mining
6. Intro to NLP and Network Analysis
7. Creating Network Visualizations

This analysis part of the project involved scraping the text from the Wikipedia page [Key Events of the 20th Century](https://en.wikipedia.org/wiki/Key_events_of_the_20th_century) then analysing the frequencies of the most common words.  Various libraries were used relating to Natural Language Processing while data was prepared to create network visualizations in the final task.
